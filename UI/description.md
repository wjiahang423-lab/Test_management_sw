
测试用例管理与执行软件 —— 软件需求规格说明书
 
项目名称：测试用例管理与执行软件
开发技术：Python + PyQt5
架构原则：UI页面文件与业务代码完全分离
运行要求：支持7×24小时长时间稳定运行；采用QT多线程 + Python线程池、异步任务机制；界面无阻塞、不卡顿；全链路异常捕获与错误处理
 
一、总体功能概述
 
软件分为三大核心业务页面：执行页面、管理页面、系统设置页面；配套用户权限体系、全局变量管理、多类型测试用例引擎、日志与报告存储方案。
权限分级：管理员、操作员两级权限控制。
 
二、用户权限管理模块
 
1. 用户角色
- 管理员：拥有全部功能权限，可访问执行页面、管理页面、设置页面，支持测试计划增删改查、变量编辑、清零统计数据等所有操作
- 操作员：仅允许进入【执行页面】，无法访问管理页面、系统设置页面，不能编辑测试计划与全局变量
2. 基础账号功能：用户新增、删除、修改账号、修改密码
3. 登录校验：软件启动强制登录，权限动态控制菜单/页面入口可见性
4. 用户管理页面带一键分权，默认不开启，如果开启则启动时 下一次启动软件启用用户登录页面，不开启则直接进入管理页面
 
三、【执行页面】需求（操作员可见核心页面）
 
3.1 基础操作
 
1. 打开文件夹，选中本地测试计划（PLAN）文件加载
2. 控制按钮：开始执行、暂停执行；支持中途暂停、恢复运行
3. 执行状态显示 （PASS FAIL），要求 ：状态显示内容要明显，让操作人员一眼可以看到，常时间显示状态直到下一个SN改变，。
4. 树形/列表展示：测试步骤可展开/收起，实时展示每条用例运行状态（待执行/运行中/成功/失败/跳过）
 
3.2 日志面板
 
- 默认隐藏执行日志
- 【日志】切换按钮：点击展开/收起实时运行日志
 
3.3 生产统计看板
 
实时展示数据：
 
- 当前SN码展示区域
- 总测试数量、良品数量、良率、不良率
- 清零按钮：点击弹窗要求输入密码；初始密码固定 0000 ；密码校验通过后方可清空所有统计数据
 
3.4 UI性能约束
 
所有测试任务后台异步执行，禁止主线程阻塞，界面操作持续响应。
 
3.5 连续测试执行 选项，默认单次执行

    生产线上的连续执行，一个测试计划连续执行，如未输入SN则一直等待 输入，测试状态一直保持上一个状态

四、【管理页面】需求（仅管理员可访问）
 
核心功能：测试计划（PLAN）新增、编辑、删除、另存、单独保存，每个PLAN独立文件持久化。
 
层级结构：测试PLAN → 多个测试序列 → 每个序列包含多条测试用例
 
4.1 层级结构定义
 
1. 测试PLAN（测试方案）
2. 测试序列：一个PLAN可新增多条序列，支持增删、修改序列名称
3. 测试用例：一条序列下可添加数十条测试用例
 
4.2 测试PLAN全局存储策略（PLAN独立配置）
 
每条测试计划独立配置日志&报告存储方式：
 
- 模式1：本地存储，自动保存运行日志、HTML测试报告
- 模式2：远程存储，调用远端接口上报数据；需配置远程接口地址、表单字段信息
单测试PLAN私有配置（每个PLAN独立设置，互不影响）
 
    编辑测试计划时内嵌独立设置面板：
 
    1. MES服务器地址、交互接口、上报报文内容模板
    2. 远程文件存储服务器地址
    3. 远程数据库IP、目标数据表/表单名称
 
 
4.3 单条测试用例通用配置项（所有类型共用）
 
1. 执行超时时间（单位ms）；支持设置 -1 代表无限等待
2. 失败重试次数
3. 失败策略二选一：失败后暂停执行 / 失败继续执行下一条用例
4. 选择执行类型（5大类：Action / Delay / Pop / Measurement / Loop）
 
4.4 五类执行类型详细定义
 
（1）Action 类型
 
- 用途：仅执行指定函数，不校验返回结果
- 页面配置项：脚本文件路径、目标函数名称
- 报告输出：记录执行函数名称、执行类型，不做结果判定
 
（2）Delay 延时类型
 
- ms级精确延时
- 配置项：延时时长（毫秒）
- 报告记录：实际执行耗时
 
（3）Pop 人机交互弹窗类型
 
- 配置自定义弹窗展示文本（文本长度无限制）
- 弹窗内置两个按钮：确认/取消
- 返回值： True / False ，供后续步骤逻辑调用
 
（4）Measurement 测量执行类型
 
1. 自定义展示文本
2. 选择外部脚本路径，自动解析脚本内所有函数并下拉选择
3. 选中函数后，自动加载入参列表、返回数据
4. 参数、返回值自动识别类型： int / str / float / list / dict 
5. 返回值支持绑定系统全局变量，执行完成自动赋值
 
（5）Loop 循环批量测试类型
 
- 适用场景：同一函数、同一测试逻辑，批量多组测试数据循环执行
- 配置项：
- YAML数据文件路径（存放多组测试session数据、判定阈值）
- 测试脚本路径，自动读取可选函数名称
- 执行规则：
1. 加载YAML中每组session数据循环执行目标函数
2. 阈值、判定规则优先读取页面配置；页面无配置则使用YAML内部定义
- 页面展示：循环所有测试结果平铺展示
- HTML报告：完整输出每一组session测试数据与执行结果
 
五、全局变量管理模块（管理员权限）
 
独立页面嵌入管理页面：
 
- 变量：新增、删除、修改、查询
- 变量数据类型可选： int / str / float / list / dict 
- 变量全局作用域：可供所有测试用例读取、赋值（Measurement、Loop、Pop等类型均可使用）
- 在帮助中说明如何使用函数
 
六、系统【设置页面】（全局基础设置，管理员）
 
全局软件基础参数：
 
1. UI界面字体大小调整
2. 主窗口默认尺寸设置
3. 测试整体执行速度调节（预留调速接口，用于延时系数统一缩放）
 
七、管理页面 ->调试按钮、切换执行页面按钮
  1 点击 调试 按钮 可以在管理页面执行测试
  2 点击 切换执行页面 按钮， 切换到执行页面窗口
   
   

八、底层技术架构非功能需求
 
1. 代码规范
UI界面(.ui)文件与业务逻辑代码彻底分离，通过QtUiLoader加载ui文件，禁止业务逻辑写在UI定义内。
2. 并发架构
- 使用Qt主线程负责UI渲染
- 测试任务使用Python线程池 + QThread异步封装
- 严格禁止在工作线程直接操作UI控件，通过信号槽通信
3. 稳定性
- 面向7×24小时长时间不间断运行；内存泄漏防范
- 所有外部函数调用、脚本执行、网络请求、文件读写增加try-except捕获，完善异常处理
- 异常日志统一收集，不会造成程序崩溃
4. 界面体验
后台任务运行时界面无卡死、无冻结；暂停/启停操作实时响应
