# EOL 测试用例管理与执行软件 —— 操作手册

版本：1.0  
日期：2026-09-15  
适用对象：操作员、测试工程师、产线管理人员

---

## 1. 文档说明

本文档介绍「EOL 测试用例管理与执行软件」的日常操作流程，包括登录、执行测试、管理测试计划、配置系统参数等。

---

## 2. 启动与登录

### 2.1 启动软件

**源码方式：**

```bash
cd Test_management_sw
python3 main.py
```

**打包方式：** 双击 `EOL`（Linux）或 `EOL.exe`（Windows）。

### 2.2 登录

若已开启「一键分权」，启动后显示登录页面：

1. 输入 **用户名** 和 **密码**
2. 选择 **角色**（管理员/操作员），角色必须与账号一致
3. 点击 **登录**

**默认账号：**

| 用户名 | 密码 | 角色 |
|--------|------|------|
| admin | admin | 管理员 |
| operator | operator | 操作员 |

> 若未开启一键分权，软件直接进入管理页面（以管理员身份）。

### 2.3 界面概览

软件包含两个主页面：

- **执行页面**：操作员日常使用，执行测试、查看结果
- **管理页面**：管理员使用，编辑测试计划、管理变量、系统设置

管理员可通过执行页面右上角的【管理页面】按钮或快捷键 `Ctrl+M` 切换到管理页面。

## 3. 执行页面操作

执行页面是操作员的核心工作页面，分为：

- 顶部标题栏（Logo / 工位名称 / 时钟）
- 左侧（测试步骤树 + 执行日志）
- 右侧（产品信息 / 生产统计 / 总体状态 / 开始按钮）
- 底部（机器人状态栏）

### 3.1 选择测试计划

1. 点击「测试计划」输入框
2. 弹出可选计划列表（位于 `data/plans/` 目录）
3. 点击选择对应计划
4. 也可选择「浏览其他位置...」选择其他路径的计划

### 3.2 开始执行

1. 确认已选择测试计划
2. 点击右下角大号绿色【开始】按钮
3. 测试自动开始运行，按钮变为「执行中...」并置灰
4. 测试完成后按钮自动恢复，可执行下一台

### 3.3 执行过程监控

**测试步骤树：**
- 树分两级：序列（可展开）→ 用例
- 每行显示：序号 / 测试项名称 / 类型 / 状态 / 耗时
- 实时状态更新：待执行 → 运行中 → PASS / FAIL / 跳过
- Loop 用例展开后逐组显示每组 session 的结果

**总体执行状态：**
- 页面右侧以大字号醒目显示 PASS（绿色）/ FAIL（红色）
- 持续显示直到下一轮测试开始

**日志面板：**
- 位于左侧测试步骤树下方，默认隐藏
- 点击【显示日志】展开实时日志
- 可点击【清空日志】清除显示内容

### 3.4 产品信息区

| 字段 | 说明 |
|------|------|
| SN 码 | 由测试脚本通过 `set_sn_to_Panel(sn)` 写入并实时显示 |
| 测试计划 | 当前加载的计划名称 |
| 当前批次 | 在计划设置中配置 |
| 测试节拍 | 最近一轮测试耗时（秒） |

### 3.5 生产统计看板

| 指标 | 说明 |
|------|------|
| 总数量 | 当天累计测试产品数 |
| 良品数 | 当天 PASS 数量 |
| 不良品数 | 当天 FAIL 数量 |
| 良率 | 良品数/总数量 百分比 |
| 不良率 | 不良品数/总数量 百分比 |

**清零统计：**
1. 点击【清零统计】按钮
2. 输入清零密码（初始 `0000`）
3. 确认清零（仅清空当天数据）

### 3.6 机器人状态栏

页面最底部显示机器人实时状态：温度 / 电流 / 电压 / 电池百分比。由测试脚本通过以下 API 更新：

- `set_robot_temperature(v)` — 温度
- `set_robot_current(v)` — 电流
- `set_robot_voltage(v)` — 电压
- `set_robot_battery(v)` — 电池百分比
- `set_robot_status(temperature=25.5, current=1.2, voltage=12.3, battery=87)` — 批量更新

## 4. 管理页面操作

管理页面左侧导航包含四个子页面：测试计划管理 / 全局变量管理 / 系统设置 / 用户管理。

### 4.1 测试计划管理

#### 层级结构

```
测试计划 PLAN（独立 .plan 文件）
  └─ 测试序列（可增删改）
       └─ 测试用例（一条序列下可添加多条）
```

#### 工具栏操作

| 按钮 | 功能 |
|------|------|
| 新建计划 | 创建空计划 |
| 打开计划 | 打开已有 .plan 文件 |
| 保存 / 另存为 | 保存当前计划 |
| 删除计划 | 删除当前计划文件 |
| 计划设置 | 配置上报地址、批次、工位等 |
| 调试执行 | 在管理页内直接执行（不入统计） |
| 切换执行页面 | 跳转到执行页面 |
| 帮助 | 内置 API 与变量使用说明 |

#### 新增序列

1. 选中计划节点
2. 点击【新增序列】
3. 输入序列名称

#### 新增用例

1. 选中目标序列
2. 点击【新增用例】
3. 在弹出的编辑窗口配置用例

#### 用例编辑

**通用配置：**
- 用例名称
- 执行类型（Action/Delay/Pop/Measurement/Loop）
- 跳过此用例（勾选后不执行，不影响统计）
- 超时时间（ms），-1 为无限等待
- 失败重试次数
- 失败策略（暂停/继续）

**Action 用例：**
- 选择脚本路径和函数名
- 仅执行函数，不做结果判定

**Delay 用例：**
- 设置延时时长和单位（毫秒/秒/分钟）

**Pop 用例：**
- 设置弹窗标题和内容
- 配置两个按钮的文本
- 选择是否模态阻塞

**Measurement 用例：**
- 选择脚本路径和函数名
- 自动解析函数参数和返回值
- 配置输入参数的值（直接值或绑定全局变量）
- 配置返回值判定方式（等于/大于/小于/范围内/包含/长度）
- 配置阈值范围

**Loop 用例：**
- 选择 YAML 数据文件
- 选择脚本路径和执行函数
- 可选择解析函数（可选）
- 配置 session 键名（默认 sessions）

### 4.2 计划设置

点击工具栏【计划设置】，配置当前测试计划的独立参数：

| 配置项 | 说明 |
|--------|------|
| 当前批次 | 批次号，随上报数据发送 |
| 存储模式 | 本地 / 远程 |
| 远程存储报告和日志 | 开关 + 上传服务器地址 |
| 逐用例 JSON 数据上报 | 开关 + 上报接口地址 |
| MES 服务器地址 | MES 交互地址 |
| 上传服务器地址 | 报告/日志上传地址 |

### 4.3 全局变量管理

**支持类型：** int / str / float / list / dict

**操作：**
1. 点击左侧【全局变量管理】
2. 点击【新增变量】输入名称和值
3. 编辑/删除已有变量
4. 点击【保存计划】将变量随计划保存

**使用方式：**
- 在 Measurement 用例中，参数「来源」选「变量」，值列填变量名
- 在脚本中通过 `get_variable("变量名")` / `set_variable("变量名", value)` 读写
- 不同计划的变量互相独立

### 4.4 系统设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| UI 字体大小 | 全局字体缩放 | 10 |
| 主窗口尺寸 | 宽 x 高 | 1280 x 800 |
| 执行速度系数 | 延时统一缩放 | 1.0 |
| 清零统计密码 | 统计清零密码 | 0000 |

点击【保存设置】后【应用】生效。

### 4.5 用户管理

**操作：**
- 新增/修改/删除账号
- 修改密码（管理员直接重置）
- 开启/关闭一键分权

**一键分权：**
- 开启：下次启动显示登录页，必须登录后使用
- 关闭：下次启动直接进入管理页面

## 5. 测试计划配置流程

### 5.1 新建测试计划

1. 管理页面 → 点击【新建计划】
2. 输入计划名称
3. 点击【保存】→ 选择保存路径（`data/plans/` 目录下）
4. 点击【计划设置】配置批次、上报地址等

### 5.2 添加测试用例

1. 选中计划 → 点击【新增序列】→ 输入序列名称
2. 选中序列 → 点击【新增用例】
3. 在编辑窗口配置：
   - 选择用例类型（Action/Measurement/Loop 等）
   - 选择脚本文件和函数
   - 配置参数和判定条件
4. 点击确定保存用例

### 5.3 配置 Loop 用例

1. 新增用例，类型选 Loop
2. 选择 YAML 数据文件
3. 选择脚本文件和执行函数
4. 确认 session 键名（默认 `sessions`）

YAML 文件格式：

```yaml
sessions:
  - name: "测试项1"
    path: "/api/voltage"
    expected: 12
    lower: 11
    upper: 13
    timeout: 3

  - name: "测试项2"
    path: "/api/current"
    expected: 1
    lower: 0.6
    upper: 1.2
    timeout: 3
```

### 5.4 配置远程上报

1. 点击【计划设置】
2. 开启「逐用例 JSON 数据上报」
3. 填写上报接口地址
4. 若需认证，填写用户名和密码
5. 脚本中调用 `set_upload_key(key)` 回填密钥

## 6. 数据存储与报告

### 6.1 本地存储

每次测试结束自动生成：
- HTML 测试报告：`data/reports/计划名_SN_时间戳.html`
- 运行日志：`data/logs/计划名_时间戳.log`

**自动清理：** 本地只保留当天的报告和日志，历史文件自动删除。

### 6.2 远程存储

在计划设置中开启后，每轮测试结束自动上传：
- HTML 报告和运行日志 → 上传到配置的服务器地址
- 逐用例 JSON 数据 → POST 到配置的上报接口
- MES 结果汇总 → POST 到 MES 服务器

### 6.3 生产统计

统计数据存储在 `data/stats.ini`，按日期分节累加：
- 总数量、良品数、不良品数、良率、不良率
- 清零仅清空当天数据，历史数据保留
- 可用文本编辑器直接修改文件

## 8. 常见问题

### Q1: 启动后如何进入登录页？

在管理页面 → 用户管理 → 勾选「开启一键分权」→ 重启软件。

### Q2: 脚本函数列表为空？

- 确认脚本路径正确
- 确认脚本无语法错误
- 确认脚本依赖的第三方库已安装（放入 `data/ext_packages/`）

### Q3: 测试计划拷到另一台电脑后脚本找不到路径？

计划保存时脚本路径会自动转为相对路径，打开时自动解析。确保脚本放在 `scripts/` 目录下，并连同脚本一起拷贝。

### Q4: 停止执行会计入生产统计吗？

不会。手动停止的运行不计入统计。

### Q5: 报告和日志会越积越多吗？

不会。软件本地只保留当天文件，自动清理历史。如需长期归档，请开启远程存储。

### Q6: 返回值是 list/dict 时怎么判定？

- 返回项填 `return` 取整个对象
- dict 填键名（如 `voltage`）取对应值
- list 填下标（如 `0`）取对应元素
- 判定方式可选等于、包含、长度等

### Q7: Loop 用例 YAML 格式？

```yaml
sessions:
  - name: "测试项名称"
    # 自定义字段（脚本通过 params.get() 读取）
    expected: 期望值
    lower: 下限
    upper: 上限
    timeout: 超时秒数
```

### Q8: 如何让脚本自己弹窗获取 SN？

脚本内调用 `test_api.set_sn_to_Panel(sn)` 即可。

### Q9: 打包后程序运行异常？

- 检查 `data/` 目录是否与主程序同级
- 检查 `_internal/` 目录是否完整
- 查看日志 `data/logs/system_*.log`

### Q10: 远程上报失败？

- 检查网络连通性
- 检查计划设置中的 URL
- 检查服务器是否返回 HTTP 2xx
- 失败数据保存在 `data/pending_uploads/`，下次运行自动重试
