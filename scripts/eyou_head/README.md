# 头部意优电机测试脚本

本目录保留头部意优关节的 CANopen 底层驱动和测试函数。

## 测试函数

- `test_connect(channel=0)`：连接 CAN 总线，返回 `bool`。
- `test_close()`：关闭 CAN 总线，返回 `bool`。
- `test_scan_nodes()`：扫描总线节点，返回节点数量。
- `test_read_sn_(node=None)`：读取两个节点的 `0x2082` 并写入面板 SN。
- `test_enable(node=1)`：使能 CANopen 节点，返回 `bool`。
- `test_enable_position(node=1)`：切换到 PP 位置模式并使能，返回 `bool`。
- `test_disable(node=1)`：失能节点、释放电机输出，便于人工手动转动关节，返回 `bool`。
- `test_move_angle(node=1, angle=30, speed=5, acc=20, timeout=30)`：先使能，再按角度定位
  （相对软件零点），返回包含 `actual_deg`、目标/实际脉冲的字典；超时或通信失败抛异常。
- `test_set_torque(node=1, torque=0)`：设置扭矩模式并写入扭矩。
- `test_zero_position(node=1)`：执行 `0x2262` 机械标零，返回标零后 `0x6064` 的回读值（`float`）。
- `test_return_zero(node=1, speed=5, acc=20, timeout=30)`：回到 `0x2262` 标定的机械零点，
  返回包含 `actual_deg` 的字典。
- `test_read_angle(node=1)`：读取 `0x6064`，减去 `test_zero_position` 记录的软件零点，
  再按 `0x6091:02` 当量换算角度，返回 `float`，单位为度。
- `test_read_info(node=1, address="0x1008")`：读取 SDO，返回字符串；通信失败抛异常。
- `test_write_info(node=1, address="0x2304", value="340")`：写入 SDO 并回读比对，返回 `bool`。

## 身份信息地址（按意优 SDK）

| 用途 | 对象 |
| --- | --- |
| 产品型号/设备名 PN | `0x1008:00`（字符串，分段上传） |
| 硬件版本 HW | `0x1009:00`（字符串） |
| 软件版本 SW | `0x100A:00`（字符串，可能分段上传） |
| 产品代码 | `0x1018:02`（uint32） |
| 序列号 SN | `0x1018:04`（uint32） |

`0x2082/0x2083/0x2084` 在部分新固件上返回 `0x00`，不要再用它们读 SN/HW/SW。
`read_string` 已支持标准 SDO 分段上传（0x41 + 0x60/0x61），所以 0x1008/0x100A
这类长字符串也能读取。

## 写入说明（0x2304 / 0x222a 等）

`test_write_info` 的 `value` 虽然从计划里按字符串传入，但会自动按**整数**处理：

- `"340"` → 写入 `0x00000154`，不是 ASCII `"340"`
- 写入长度优先沿用对象当前长度（例如这两个对象是 32 位，就写 4 字节）
- 写完后按数值回读比对，而不是比较 `"340"` 和 `"340 (0x154)"` 字符串
- 非数字字符串仍按 ASCII 写入（最多 4 字节）

已验证：

```
0x2304: 340 -> 341 -> 340   通过
0x222a: 4000 -> 4001 -> 4000 通过
```

## 角度换算与零点

```
角度(°) = (0x6064脉冲 - 软件零点) × 360 / 0x6091:02当量
```

`test_zero_position` **不是清空编码器计数**，而是把当前机械位置写成 0 位。
流程与「意优RP-CANFD调试器」`app/worker.py::set_mech_home` 保持一致：

1. `0x2262:00` 写 1 字节值 `1`；
2. `0x1010:01` 写 4 字节 `65 76 61 73`（设备要求的保存签名，即 ASCII `"evas"`）；
3. 每 0.1 s 回读 `0x6064`，最多 20 次；严格等于 `0` 表示驱动器标零成功。

无论驱动器是否回到 0，都会把实际回读值记为软件零点并返回，由计划阈值判定。
最新头部计划把标零判定设为 `-1000~1000` 脉冲（约 ±0.69°）；需要更严格时改小即可。
写入 `0x2262`/`0x1010` 或读取 `0x6064` 失败时直接抛异常，不再回退掩盖故障。

标零完成后会失能电机，方便后续手动转动。计划中在每个“手动对零位”弹窗前
都会先执行 `test_disable`，所以标零前关节可以手动扳动。

因此标零后 `test_read_angle` 读到的是相对该机械零点的真实角度，读数正常是预期结果。
软件重启后需要重新标零（或依赖设备已保存的机械零点，在同一轮测试内先标零再读角度）。

## 角度控制（PP 位置模式）

`test_move_angle` 的执行顺序：

1. 先把 `0x6064` 实际位置写入 `0x607A`，再写 `0x6060:00 = 1` 切到 PP 位置模式
   （手册要求切位置模式前先对齐目标位置，避免使能瞬间跳动）；
2. 按 `0x06 -> 0x07 -> 0x0F` 使能，每步间隔 `0.6s`，再轮询 `0x6041` bit2
   确认进入 Operation enabled（手册 3.1：T2=500ms、T3>500ms；间隔太短会停在
   “等待打开伺服使能”，状态字 `0x0333`）；
3. 写 `0x6081/0x6083/0x6084` 轮廓速度、加速度、减速度；
4. 目标脉冲 = 软件零点 + `角度 / 360 × 0x6091:02 当量`；
5. 写 `0x607A` 目标位置，再写控制字 `0x2F -> 0x3F` 触发 PP 运动；
6. 轮询 `0x6041` bit10 和 `0x6064` 位置（0.5° 容差），到位返回实际角度。

说明：

- 角度为正表示电机正方向，负表示反方向；如果现场方向与图片相反，把计划里的
  `angle` 正负对调即可。
- 角度默认钳制在 `±90°`，超出行程会记录并钳制。
- 计划 19180 的 4 个“控制关节旋转 30 度”用例已改为 **Measurement**，因为 EOL 的
  Action 类型不会把 `params` 传给函数；改成 Measurement 才能传 `node/angle`，
  并把 `actual_deg` 写进报告。
- 如果设备不支持 `0x6081/0x6083/0x6084`，驱动会记录警告并沿用驱动器默认 PP 参数，
  仍继续执行定位。

## 关于“设置扭矩模式”用例

计划中的 `设置关节扭矩模式` 用例当前为 `skip=true`：驱动写入的是
`0x6060` 子索引 4，而该设备没有这个子索引，执行会失败。需要扭矩模式时请先确认
设备支持的对象写法后再启用。

## 节点与地址

节点使用 CANopen 的 1-based node ID（头部节点为 1、2）。
SDO 地址支持 `0x1008`、`"0x1018:04"` 和 `"0x1018/04"` 写法。

## CAN 适配器

优先使用创芯 USB-CANFD（`USB_CAN_FD_Driver/libcontrolcanfd.so`），
找不到设备时回退 ZLG（`library/` + `zlgcan`）。设备为
`04d8:0053`，Linux 下需要 udev 权限规则。
