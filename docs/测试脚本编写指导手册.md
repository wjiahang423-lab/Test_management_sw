## 2. 脚本文件基础

### 2.1 存放位置

测试脚本文件必须存放在 `scripts/` 目录下（或其子目录），引擎通过 `script_loader.py` 自动扫描该目录。

```
scripts/
├── demo_instrument.py       # 示例脚本
├── auto_api.py              # 全功能测试脚本
├── cit_api.py               # CIT 协议测试脚本
├── scan_sn.py               # SN 扫码脚本
├── 自定义脚本.py             # 你的脚本
├── 子目录/                  # 子目录下的脚本也可被加载
│   └── subdir_script.py
└── *.yaml                   # Loop 测试数据文件
```

### 2.2 基本模板

```python
# -*- coding: utf-8 -*-
"""脚本说明：一句话描述本脚本的用途。"""
import test_api


def my_function(param1, param2="default"):
    """函数说明：会被用例编辑器解析并展示在界面上。
    
    Args:
        param1: 参数说明
        param2: 参数说明，默认值
    
    Returns:
        返回值会被引擎用于判定用例结果
    """
    # 你的测试逻辑
    test_api.log("正在执行: %s" % param1)
    
    result = do_something(param1, param2)
    return result
```

### 2.3 命名规则

- 文件名：字母/数字/下划线，如 `demo_instrument.py`
- 函数名：字母/数字/下划线，不能以数字开头
- **私有函数**（以 `_` 开头）不出现在用例编辑器的函数选择列表中
- 脚本修改后引擎自动重新加载（按文件 mtime 判断，无需重启）

### 2.4 函数签名解析

引擎自动解析函数签名，在用例编辑界面生成参数输入框：

```python
# 无参数 → 界面无参数输入框
def simple_action():
    return True

# 带默认值 → 界面显示参数名和默认值，可修改
def measure_voltage(channel=1, timeout=5):
    return {"value": 12.0}

# 类型注解 → 引擎辅助类型转换
def add(a: int, b: int) -> int:
    return a + b
```

## 4. 五种用例类型

### 4.1 Action（动作用例）

**用途：** 执行操作，不做自动判定。如上电、发送指令、保存数据。

**脚本示例：**

```python
def power_on(voltage=12.0, current=1.5):
    """上电操作"""
    import time
    time.sleep(0.2)
    sn = test_api.get_sn()
    test_api.log("power_on: SN=%s, 电压=%.1fV" % (sn, voltage))
    power = voltage * current
    test_api.set_display_info("功耗", "%.2fW" % power)
    return {"power": power, "voltage": voltage, "current": current, "ok": True}
```

**判定规则：**
- 函数正常执行（无异常、未超时）即 PASS；执行异常或超时 → FAIL
- 返回值不参与判定；若返回 `dict`，则作为该用例的结构化结果（payload）随报告以参数表展示，并在逐用例 JSON 上报中按 `extrinsic` / `intrinsic` / `parameters` 等对应键写入

**适用场景：**
- 上电/断电操作
- 发送控制指令
- 保存标定数据
- 不需要判定结果的辅助操作

### 4.2 Delay（延时用例）

**用途：** 等待指定时间。

**配置方式：** 无需脚本函数，在用例编辑界面直接配置延时时长和单位。

**配置字段：**
- `delay_ms`：等待毫秒数
- 执行受全局「速度系数」统一缩放

**适用场景：**
- 设备启动等待
- 稳定性等待
- 工序间隔

### 4.3 Pop（人机交互用例）

**用途：** 弹窗等待人工确认。

**配置方式：** 无需脚本函数，在用例编辑界面配置弹窗标题和内容。

**判定规则：**
- 用户点击「确认」→ PASS
- 用户点击「取消」→ FAIL
- 弹窗为模态阻塞，等待操作员操作；测试被停止时随之中断

**适用场景：**
- 外观检查确认
- 人工测量记录
- 操作指引确认

### 4.4 Measurement（测量用例）

**用途：** 测量一个值并与阈值比较。

#### 返回标量值

```python
def measure_voltage(channel=1):
    """测量电压，返回数值"""
    import random
    value = 12.0 + random.uniform(-0.1, 0.1)
    return round(value, 3)
```

#### 返回字典

```python
def measure_voltage(channel=1):
    """测量电压，返回字典"""
    value = 12.0
    return {"voltage": value, "unit": "V", "channel": channel}
```

#### 自描述模式（推荐）

```python
def measure_custom(params: dict) -> dict:
    """自描述测量：脚本自行判定"""
    value = 12.3
    expected = 12.0
    lower, upper = 11.0, 13.0
    passed = lower <= value <= upper
    
    test_api.set_measure_result(
        value=value, expected=expected, unit="V",
        lower=lower, upper=upper, passed=passed,
        message="电压 %.3fV 在 [%.1f, %.1f] 范围内" % (value, lower, upper)
    )
    return {"value": value, "pass": passed}
```

#### 判定模式

| 模式 | 阈值写法 | 含义 |
|------|---------|------|
| 等于 | `12` | 实际值 == 12 |
| 不等于 | `100` | 实际值 != 100 |
| 范围内 | `11,13` 或 `11~13` | 11 <= 实际值 <= 13 |
| 大于 | `200`（判定方式选「大于」） | 实际值 > 200 |
| 小于 | `0.5`（判定方式选「小于」） | 实际值 < 0.5 |
| 包含 | `ok` | 返回值包含该文本（list/dict 按元素判断） |
| 长度 | `3~8` | 返回 list/dict 的长度在区间内（也支持 `>3` / `<5`） |

#### 返回值提取（返回项）

| 返回类型 | 返回项写法 | 效果 |
|---------|-----------|------|
| 标量 | `return` | 直接用该值判定 |
| dict | `return` 或 `*` | 取整个 dict |
| dict | 键名，如 `voltage` | 取 `ret["voltage"]` |
| dict 嵌套 | 点号路径，如 `nested.a` | 取深层值 |
| list | 下标 `0` / `1` / `2` | 取对应元素 |

### 4.5 Loop（循环用例）

**用途：** 从 YAML 文件批量读取测试数据，逐条调用脚本函数。

#### 脚本写法

```python
def loop_test_entry(params):
    """Loop 统一入口：每个 session 调用一次。
    
    Args:
        params: YAML 中一个 session 的全部字段（dict）
    
    Returns:
        dict: 必须包含 "pass" 字段（True/False）
    """
    item_name = params.get("name", "unknown")
    url = params.get("path", "")
    
    # 你的测试逻辑
    ok, resp = do_request(url)
    
    # 判定
    passed = ok and resp.get("code") == 0
    
    return {
        "value": resp.get("data"),
        "pass": passed,
        "message": "%s: %s" % (item_name, "OK" if passed else "FAIL")
    }
```

#### 函数调用自适应

引擎根据函数签名自动适配调用方式：

```python
# 单 dict 参数 → 传整条 YAML session
def func(params: dict): ...

# 多形参 → 按字段名传参
def func(path, expected, timeout): ...

# 无参函数 → 直接调用
def func(): ...
```

#### 判定优先级

1. **函数显式判定**（优先）：函数返回的 dict 中 `pass` / `passed` 若为布尔 `False`，直接判定 FAIL（以函数为准）；若为 `True` 不生效，继续走期望值逐键判定（更严格，防漏判）。
2. **期望值逐键判定**：依次用 `expected` 的每个键与返回值对应字段比较；页面覆盖配置的 expected 优先于 YAML 同名键；范围写法（`20~30`、`11,13`）自动按「范围内」判定，其余按「等于」。
3. **脚本返回值自动判定**：未配置 expected 时，从返回值中查找 `pass` / `passed` / `ok` / `success` / `result` / `status` 字段（布尔值，或 `pass` / `ok` / `true` / `success` / `yes` 等字符串 token），无状态字段则仅记录、不判 FAIL。

> 脚本通过 `test_api.set_measure_result(...)` 写入的自描述字段会合并进当前 session 结果（函数返回 dict 的字段优先，API 仅补充缺失键），随报告展示与逐条 JSON 上报。

## 5. Loop 数据 YAML 配置

### 5.1 文件格式

```yaml
# 文件名：demo_loop.yaml
sessions:
  - name: "测试项名称1"         # 必填：显示在报告中
    # 以下字段按需添加
    param1: value1
    expected: expected_value     # 期望值（可选）
    lower: 10                    # 下限（可选）
    upper: 20                    # 上限（可选）
    timeout: 5                   # 超时（可选，数据字段，脚本读取）

  - name: "测试项名称2"
    param1: value3
```

### 5.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 测试项名称，显示在报告和日志中 |
| `expected` | any | 否 | 期望值，可用于判定 |
| `lower` | number | 否 | 阈值下限 |
| `upper` | number | 否 | 阈值上限 |
| `timeout` | number | 否 | 数据字段：脚本读取用作脚本内请求超时（示例脚本 `params.get('timeout', 5)`）；整条 Loop 用例的引擎超时在用例编辑界面配置 |
| 其他 | any | 否 | 自定义字段，脚本通过 `params.get()` 读取 |

### 5.3 常用模式

**命令接口测试：**

```yaml
sessions:
```

### 6.1 HTTP 接口测试脚本

```python
# -*- coding: utf-8 -*-
"""HTTP 接口测试脚本：演示 GET/POST 请求与 JSON 判定"""
import requests
import test_api

SERVER = "http://10.5.35.49:5000"


def ping(params=None):
    """动作：检查服务是否存活"""
    try:
        r = requests.get(f"{SERVER}/status", timeout=5)
        ok = r.status_code == 200
        test_api.log("ping: %s" % ("OK" if ok else "FAIL"))
        return ok
    except Exception as e:
        test_api.log("ping 失败: %s" % e)
        return False


def measure_voltage(params=None):
    """测量：获取电压值"""
    try:
        r = requests.get(f"{SERVER}/api/voltage", timeout=5)
        data = r.json()
        value = data["data"]["value"]
        test_api.log("电压: %.3f V" % value)
        return value
    except Exception as e:
        test_api.log("测量失败: %s" % e)
        return 0


def loop_api_test(params):
    """Loop：逐条测试 API 接口"""
    name = params.get("name", "unknown")
    path = params.get("path", "/api/status")
    expected_code = params.get("expected_code", 0)
    timeout = params.get("timeout", 5)

    try:
        r = requests.get(f"{SERVER}{path}", timeout=timeout)
        resp = r.json()
        code = resp.get("code", -1)
        passed = code == expected_code

        test_api.set_measure_value(code, unit="code")
        test_api.set_measure_expected(expected_code)
        test_api.set_measure_message(
            "%s: code=%s expected=%s" % (name, code, expected_code)
        )
        return {"value": code, "pass": passed, "code": code}
    except Exception as e:
        test_api.log("%s FAIL: %s" % (name, e))
        return {"value": None, "pass": False, "message": str(e)}
```

### 6.2 通用 HTTP 请求封装

```python
# -*- coding: utf-8 -*-
"""通用接口测试封装"""
import requests
import test_api


def request_api(url, method="GET", params=None, headers=None, timeout=10):
    """封装 requests，返回 (success, data_or_error)"""
    try:
        if method.upper() == "POST":
            resp = requests.post(url, json=params, headers=headers, timeout=timeout)
        else:
            resp = requests.get(url, params=params, headers=headers, timeout=timeout)
        resp.raise_for_status()
        return True, resp.json() if resp.content else {}
    except Exception as e:
        return False, "%s: %s" % (type(e).__name__, e)


def compare_thresholds(item_name, value, lower=None, upper=None, expected=None):
    """阈值对比，返回 (passed, message)"""
    if upper is not None and value is not None and float(value) > float(upper):
        return False, "%s: 超上限, 实际=%s, 上限=%s" % (item_name, value, upper)
    if lower is not None and value is not None and float(value) < float(lower):
        return False, "%s: 低于下限, 实际=%s, 下限=%s" % (item_name, value, lower)
    if expected is not None and value != expected:
        return False, "%s: 不匹配, 实际=%s, 期望=%s" % (item_name, value, expected)
    return True, "%s: 通过, 值=%s, 范围=[%s, %s]" % (item_name, value, lower, upper)


def api_test(params):
    """Loop 入口：GET 接口 + 阈值判定"""
    name = params.get("name", "test")
    url = params.get("url", "")
    method = params.get("method", "GET").upper()
    body = params.get("body")
    expected = params.get("expected")
    lower = params.get("lower")
    upper = params.get("upper")
    timeout = params.get("timeout", 5)

    ok, resp = request_api(url, method=method, params=body, timeout=timeout)
    if not ok:
        return {"value": None, "pass": False, "message": "请求失败: %s" % resp}

    data = resp.get("data", resp)
    value = data.get("value", data) if isinstance(data, dict) else data

    passed, msg = compare_thresholds(name, value, lower, upper, expected)
    test_api.set_measure_value(value)
    if expected is not None:
        test_api.set_measure_expected(expected)
    if lower is not None and upper is not None:
        test_api.set_measure_range(lower, upper)
    test_api.set_measure_message(msg)
    test_api.log(msg)

    return {"value": value, "pass": passed, "message": msg}
```

### 6.3 机器人状态读取脚本

```python
# -*- coding: utf-8 -*-
"""机器人状态读取脚本"""
import requests
import test_api

ROBOT_URL = "http://10.5.35.49:5000"


def read_robot_status(params=None):
    """动作：读取机器人状态并刷新状态栏"""
    try:
        r = requests.get(f"{ROBOT_URL}/api/robot/status", timeout=5)
        resp = r.json()
        if resp.get("code") == 0:
            d = resp["data"]
            test_api.set_robot_temperature(d.get("temperature"))
            test_api.set_robot_current(d.get("current"))
            test_api.set_robot_voltage(d.get("voltage"))
            test_api.set_robot_battery(d.get("battery"))
            test_api.log("机器人状态已更新")
            return True
    except Exception as e:
        test_api.log("读取失败: %s" % e)
    return False


def fetch_upload_key(params=None):
    """动作：从服务器获取密钥并回填"""
    try:
        sn = test_api.get_sn() or "AUTOTEST"
        r = requests.get(f"{ROBOT_URL}/api/key?sn={sn}", timeout=5)
        resp = r.json()
        if resp.get("code") == 0:
            key = resp["data"]["key"]
            test_api.set_upload_key(key)
            test_api.log("已回填上报密钥: %s" % key)
            return {"ok": True, "key": key}
    except Exception as e:
        test_api.log("获取密钥失败: %s" % e)
    return {"ok": False}
```

### 7.3 常见问题排查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 函数不出现下拉列表 | 以 `_` 开头或脚本有语法错误 | 检查函数名和脚本语法 |
| `import test_api` 报错 | 独立运行时未模拟 test_api | 使用 MockApi 模拟 |
| Loop 无结果 | YAML 格式错误或 sessions 为空 | 检查 YAML 缩进和内容 |
| 测量值判定不符 | 阈值格式错误 | 检查范围写法 `11,13` |
| JSON 上报失败 | URL 配置错误或服务不可达 | 检查计划设置和网络 |
