# 终端检测测试用例平台化管理方案

版本：1.0
日期：2026-08-26
适用范围：产线/实验室测试工位平台化管理

---

## 1. 项目概述

### 1.1 项目背景

随着生产规模的扩大和产品种类的增多，传统的单机版测试用例管理方式已无法满足多工位、多产品、多批次的生产需求。为实现测试用例的统一管理、实时下发和数据集中存储，特制定本平台化管理方案。

### 1.2 设计目标

| 目标 | 说明 |
| --- | --- |
| 平台化管理 | 测试用例集中存储在服务器，支持多产品、多工位统一管理 |
| 实时下发 | 终端电脑扫码后自动获取对应产品的测试用例 |
| 数据集中 | 测试数据实时上报服务器，支持数据分析和追溯 |
| 灵活配置 | 支持按产品、订单、工位等维度配置测试内容 |
| 高可用性 | 7×24小时稳定运行，支持无线网络环境 |

### 1.3 适用场景

- 生产线终端检测工位
- 多产品混合生产线
- 需要MES系统对接的测试场景
- 无线网络覆盖的生产现场

## 4. 数据流设计

### 4.1 核心业务流程

```
终端电脑                              后端服务器                           MES系统
   │                                    │                                 │
   │  1. 扫码获取SN                      │                                 │
   │───────────────────────────────────>│                                 │
   │                                    │                                 │
   │                                    │  2. 查询SN绑定的订单信息         │
   │                                    │────────────────────────────────>│
   │                                    │                                 │
   │                                    │  3. 返回订单信息                 │
   │                                    │<────────────────────────────────│
   │                                    │                                 │
   │                                    │  4. 根据订单配置生成测试用例     │
   │                                    │                                 │
   │  5. 返回测试用例列表               │                                 │
   │<───────────────────────────────────│                                 │
   │                                    │                                 │
   │  6. 执行测试                       │                                 │
   │                                    │                                 │
   │  7. 上报测试结果                   │                                 │
   │───────────────────────────────────>│                                 │
   │                                    │                                 │
   │                                    │  8. 存储测试数据                 │
   │                                    │                                 │
   │  9. 返回上报结果                   │                                 │
   │<───────────────────────────────────│                                 │
```

### 4.2 数据流详细说明

#### 步骤1：终端扫码
- 终端电脑扫描产品SN码
- 提取SN信息，准备查询请求

#### 步骤2-3：MES订单查询
- 服务器收到SN查询请求
- 服务器调用MES系统接口，查询SN绑定的订单信息
- MES返回订单信息（产品型号、订单号、生产批次等）

#### 步骤4-5：测试用例生成
- 服务器根据产品型号查询对应的测试用例模板
- 根据订单信息（如特殊配置）动态调整测试用例
- 生成本次测试的测试用例列表

#### 步骤6：测试执行
- 终端电脑接收测试用例列表
- 按照用例顺序执行测试
- 记录每个用例的测试结果

#### 步骤7-9：结果上报
- 测试完成后，终端电脑将结果上报服务器
- 服务器存储测试数据
- 返回上报结果给终端

```python
class ResultReporter:
    def __init__(self, server_url: str):
        self.server_url = server_url
        self.pending_reports = []
    
    def report_result(self, result: dict) -> bool:
        """上报测试结果"""
        try:
            response = self.send_to_server(result)
            if response['code'] == 0:
                return True
            else:
                self.save_to_pending(result)
                return False
        except Exception:
            self.save_to_pending(result)
            return False
    
    def retry_pending_reports(self):
        """重试未上报的结果"""
        for result in self.pending_reports[:]:
            if self.send_to_server(result):
                self.pending_reports.remove(result)
```
